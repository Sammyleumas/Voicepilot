What's real and what's simulated

  • Simulated here: speech recognition, contacts (Samuel Okafor, Samuel Adeyemi, Ada Eze) and the result of opening other apps. Nothing is sent anywhere.

  • Try it on a phone: the installable test build (about 16 MB) is published on GitHub. Get it from the latest release and install it on Android 10 or newer with installs from unknown sources allowed.
